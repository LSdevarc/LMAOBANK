# LMAOBANK 🏦

## Hold $LMAOBANK to $LMAO

The first automated revenue share vault on Solana.

### How It Works

- **Every trade** on $LMAOBANK generates creator fees
- **Our bot** claims those fees every 90 seconds
- **SOL gets swapped** to $LMAO via Jupiter
- **50% distributed** instantly to all holders
- **50% saved** for Diamond Hands — bonus drop every 1 hour

### Diamond Hands System

Hold for 1 full hour without selling and receive bonus $CUM on top of your regular distributions.

- Paper hands get nothing extra
- Loyalty pays

### No Friction

- ✓ No staking
- ✓ No locking
- ✓ No claim buttons

Just hold $LMAOBANK and $LMAO hits your wallet automatically.

## Getting Started

### Prerequisites

- Node.js 16+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build for Production

```bash
npm run build
npm run start
```

## Deployment

This project can be easily deployed to Vercel:

```bash
npm install -g vercel
vercel
```
